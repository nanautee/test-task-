# Скорость скачивания

Консольный скрипт делает 10 последовательных GET-запросов к указанному адресу.
Следующий запрос начинается только после полного чтения предыдущего ответа.
Устанавливать зависимости не нужно.

## Требования

Node.js версии 22 или новее.

## Запуск

В папке со скриптом выполните:

```sh
node index.js "https://example.com/image.jpg"
```

Адрес должен начинаться с HTTP или HTTPS. Перенаправления обрабатываются автоматически.

## Результат

- `Запросов`: количество выполненных запросов — 10.
- `Среднее время запроса`: время в секундах, включая соединение, перенаправления и полное чтение ответа.
- `Всего скачано`: суммарный размер тел всех 10 ответов в байтах, без HTTP-заголовков и служебного трафика.
- `Скорость скачивания`: общий объём данных, делённый на суммарное время запросов, в МиБ/с. Один мебибайт (МиБ) равен 1 048 576 байтам.

Ответы читаются потоком: весь файл не хранится в памяти.
Скрипт запрашивает данные без сжатия через заголовок `Accept-Encoding: identity`.
Если сервер всё равно использует сжатие, `fetch` распакует ответ:
в таком случае учитывается размер распакованных данных, а не сетевого трафика.

Ограничение времени каждого запроса — 120 секунд, включая чтение тела ответа.
При неверном адресе, сетевой ошибке, превышении времени ожидания или HTTP-статусе
вне диапазона 200–299 скрипт сообщает об ошибке и завершается с кодом 1,
не выводя неполные результаты измерения.

Измеряется скорость получения данных с конкретного адреса с учётом задержек,
а не максимальная пропускная способность интернет-соединения.
